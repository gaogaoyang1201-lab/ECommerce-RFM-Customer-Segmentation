# 电商用户消费行为分析与价值分群

基于英国某电商平台交易数据，使用 RFM 模型与 K-Means 聚类进行用户价值分层。

## 数据说明
- 来源：UCI Machine Learning Repository - Online Retail Dataset
- 规模：541,909 条交易明细，约 4,372 名客户
- 时间跨度：2010.12 - 2011.12

## 分析流程
1. 数据清洗：剔除缺失 CustomerID、退货、异常单价等记录
2. RFM 建模：计算 Recency / Frequency / Monetary 三个维度
3. 异常值处理：基于 IQR 方法识别并处理极端值
4. K-Means 聚类：肘部法确定最佳 K=4，划分四类用户
5. 可视化：雷达图展示各类 RFM 特征，柱状图展示营收贡献
6. 业务建议：针对不同客群提出差异化运营策略

## 核心发现
| 客户类型 | 人数占比 | 营收占比 |
|---|---|---|
| 潜力发展客户 | 22% | **39%** |
| 重要价值客户 | 9% | **27%** |
| 一般维护客户 | 44% | 24% |
| 流失风险客户 | 24% | 11% |
